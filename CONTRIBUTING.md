# Contributing (technical)

## Scope

- Define JSON Schema contracts and examples only
- Do not add chart calculation, interpretation copy, or open-source marketing text
- Keep examples fictional (no real PII)

## Changes

1. Update the schema under `schemas/v0/`
2. Add or adjust an example in `examples/`
3. Update `docs/` and `CHANGELOG.md` when fields or version strings change
4. Follow [docs/versioning.md](docs/versioning.md)
